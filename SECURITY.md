# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via:

1. GitHub Security Advisories (preferred):
   https://github.com/DeRuiChen258/Turbol/security/advisories/new
2. If advisories are unavailable, open an issue that does not disclose exploit
   details and ask for a private channel.

Please do not disclose security issues publicly until a fix is available.
